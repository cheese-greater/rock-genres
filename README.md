# Find Your Rock & Metal Genre

Tap the bands you like and see which rock and metal genres you love most. Each genre tile lights up as you pick its
bands, a podium shows your top three, and the board can be filtered by rock or metal, by scene, or by search, and sorted
softest to hardest, oldest first, or by your favorites.

**Visit the site: [cheese-greater.github.io/rock-genres](https://cheese-greater.github.io/rock-genres/)**

To run it locally: `npm install`, then `npm run dev`.
